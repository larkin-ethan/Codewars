<h2><a href=https://www.codewars.com/kata/5838a66eaed8c259df000003/train/python target="_blank">Palindromes Here and There</a></h2><h3>7 kyu</h3><p>An array is given with palindromic and non-palindromic numbers. A <em>palindromic</em> number is a number that is the same from a reversed order. For example <code>122</code> is not a palindromic number, but <code>202</code> is one. </p><p>Your task is to write a function that returns an array  with  only <code>1</code>s and <code>0</code>s, where  all  palindromic numbers are replaced with  a <code>1</code> and all non-palindromic  numbers  are replaced  with a <code>0</code>.</p><p>For  example:</p><pre><code>[101, 2, 85, 33, 14014]  ==&gt;  [1, 1, 0, 1, 0][45, 21, 303, 56]        ==&gt;  [0, 0, 1, 0]</code></pre>
